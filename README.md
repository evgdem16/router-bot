# Router Bot для настройки DMZ

Бот на Python, который автоматизирует процесс добавления записей DMZ (Demilitarized Zone) в интерфейс вашего роутера Huawei HG8145V5. Бот работает в циклическом режиме, проверяя наличие необходимых записей и добавляя их при необходимости.

## Основные особенности

 1 Автоматическая авторизация: Бот может автоматически войти в интерфейс вашего роутера.
 2 Проверка наличия записи DMZ: перед тем, как попытаться добавить новую запись, бот проверяет, уже ли она в таблице DMZ.  
 3 Добавление записи DMZ: если запись отсутствует, бот добавляет её, выбирая правильный хост из выпадающего списка и активируя чекбокс для активации записи.
 4 Работа в фреймах: бот может обрабатывать веб-страницы, которые используют фреймы для отображения контента.  
 5 Логирование: Все действия бота логгируются в файл bot.log и в консоль Docker.  
 6 Циклическая работа: Бот работает в цикле, проверяя роутер каждые 5 минут. 

## Требования                                                                                               

 • Python 3.8 или выше  

 • Playwright для работы с веб-страницами  
 
 • Compatible с веб-интерфейсом вашего роутера (проверено на certains TP-Link роутерах)

## Установка и настройка                                                                                    

  1 Клонировать этот репозиторий:  

    git clone https://github.com/evgdem16/router-bot.git
    cd router-bot
  2 Создать файл .env с вашими учетными данными роутера и URL:  
 
    ROUTER_URL=http://192.168.0.1
    ROUTER_USERNAME=admin
    ROUTER_PASSWORD=mysecretpassword
 3 Построить Docker-образ:                                                                               
                                                                                                         
    docker-compose build
 

4 Запустить бота в фоне:  

    docker-compose up -d
5 Логирование и отслеживание                                                                               

Логи бота можно найти в файле bot.log внутри контейнера Docker или в журнале Docker:


    docker logs router_bot -f

6 Настройка интервала проверки                                                                             

Интервал между проверками можно изменить, изменив значение переменной INTERVAL в файле main.py. По       
умолчанию он установлен на 5 минут.                                                                      

## Совместимость и адаптация                                                                                

Этот бот был разработан для конкретного роутера Huawei HG8145V5. Возможно, вам потребуется адаптировать скрипт для работы с вашим роутером, изменив селекторы CSS и шаги в процессе. Проверьте документацию вашего роутера и используйте инструменты разработчика веб-браузера, чтобы найти правильные селекторы.
